项目一

📒 记账本

一个纯 HTML / CSS / JavaScript 写成的单文件记账小应用:记账、明细、统计、月度预算一站式,数据保存在浏览器本地。

打开完整演示 ↗

项目背景

平时生活费花得糊里糊涂,月底也不知道钱去了哪里,就干脆自己写了一个记账小工具。不依赖任何框架和后端,一个 HTML 文件就能跑,打开浏览器即用,数据存在 localStorage 里,不用注册、不用担心泄露。

核心功能

  • 快捷记账:支出 / 收入一键切换,餐饮、交通、购物等分类点选即可录入。
  • 账单明细:按时间倒序查看全部流水,支持筛选和删除。
  • 统计分析:分类支出占比图 + 近 7 天支出趋势,钱花在哪一目了然。
  • 月度预算:设置每月预算并实时查看使用进度,超支会有提醒。
  • 数据管理:支持导出 / 导入备份,换设备也能带走自己的账单。

技术栈

HTML CSS JavaScript (原生) localStorage

总结与收获

这个项目让我完整走了一遍"需求 → 界面 → 逻辑 → 持久化"的小闭环:理解了状态管理和数据渲染如何配合,也练了手写图表和深色界面的配色功力。它现在也是我自己一直在用的记账工具。
